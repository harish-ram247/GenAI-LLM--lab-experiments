# Generative AI and Large Language Models Lab

A collection of laboratory exercises covering Generative AI, Large Language Models (LLMs), Foundation Models, Prompt Engineering, RAG, Multimodal AI, Fine-Tuning, Diffusion Models, and Cloud-based AI deployment.

## About

This repository contains the implementations and practical experiments performed as part of the **Generative AI and Large Language Models Laboratory**.

The experiments progress from basic text generation and prompt engineering to advanced topics such as Retrieval-Augmented Generation, multimodal AI, model fine-tuning, image generation, and cloud-based deployment.

## Objectives

The main objectives of this laboratory are to:

- Understand the fundamentals of Generative AI and Large Language Models.
- Work with pre-trained foundation models.
- Design effective prompts for different AI tasks.
- Build conversational AI applications.
- Perform text summarization, question answering, and classification.
- Implement Retrieval-Augmented Generation (RAG) systems.
- Explore AI-assisted code generation and debugging.
- Generate images using diffusion models.
- Develop multimodal AI applications.
- Fine-tune pre-trained language models for domain-specific tasks.
- Build AI-powered content generation systems.
- Deploy and evaluate Generative AI applications using cloud-based APIs.
